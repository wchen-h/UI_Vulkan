## 2. 模型结构

### 核心公式

$$ \text{eff}(B; \alpha) = b(\alpha) - \bigl[b(\alpha) - g(\alpha)\bigr] \cdot \exp\!\left(-\frac{B}{\tau(\alpha)}\right) $$

### 子函数

**渐近线 $b(\alpha)$ — 分组定义 + 下限保护：**

$$ b(\alpha) = \begin{cases}
b_{\text{FG}} = 0.8176, & \alpha < 0.8176 \text{（来自 FG 组）} \\[4pt]
b_{\text{BG}} = 0.3427, & \alpha < 0.3427 \text{（来自 BG 组）} \\[4pt]
\alpha, & \alpha \ge b_{\text{group}}
\end{cases} $$

即：$\alpha$ 较小时按所属分组的渐近线取值；若 $\alpha$ 超过分组渐近线，则 $b(\alpha) = \alpha$（不透明度保持初始值）。

这保证了 **$b(\alpha) > \alpha$ 对所有 $\alpha \in (0,1)$ 成立**。

**$B=0$ 截距 $g(\alpha)$ — 幂律形式：**

$$ g(\alpha) = \gamma \cdot \alpha^\delta $$

- 表示 HDR 窗口纯黑时与 SDR 匹配所需的有效不透明度
- $g(\alpha) < \alpha$：HDR 黑电平下对比敏感度更高，UI 看起来更通透

**时间常数 $\tau(\alpha)$ — 随 $\alpha$ 单调变化：**

$$ \tau(\alpha) = \tau_0 \cdot \left(\frac{\alpha}{0.5}\right)^{p_\tau} $$

- $\alpha = 0.5$ 处的参考时间常数 $\tau_0$
- $p_\tau < 0$：$\alpha$ 越大，$\tau$ 越小，收敛越快

收敛至 90% 渐近值所需的亮度：$B_{90\%} = \tau(\alpha) \cdot \ln(10) \approx 2.303 \cdot \tau(\alpha)$

## 6. 外推与适用范围

### 有效范围

- $B \in [0, 1000] \text{ nits}$（拟合覆盖 30–1000）
- $\alpha \in [0.05, 0.85]$（拟合覆盖 0.14–0.71，外推至 0.85 可靠）

### $\alpha > 0.82$ 时的行为

当 $\alpha$ 超过 FG 渐近线 $b_{\text{FG}} = 0.8176$ 时，$b = \alpha$。这是因为极高不透明度 UI 的初始值已接近感知极限，背景亮度变化对其影响很小。示例如下：

| $\alpha$ | $b$ | $g(0)$ | $\tau$ | $B_{90\%}$ |
|:-------:|:---:|:------:|:-----:|:---------:|
| 0.75 | 0.8176 | 0.1552 | 71.8 | 165 |
| 0.80 | 0.8176 | 0.1562 | 68.6 | 158 |
| 0.85 | **0.8500** (= $\alpha$) | 0.1571 | 65.8 | 152 |
| 0.90 | **0.9000** (= $\alpha$) | 0.1580 | 63.2 | 146 |

### 使用限制

- 该模型基于 `1_1839_724` 单张中性色 UI 拟合，$\alpha_0$ 不连续（仅 0.2285 和 0.7054 两组）。**$\alpha$ 在 0.23–0.42 之间的 UI 需要更多数据验证插值合理性。**
- FG 和 BG 的分组边界为 $\alpha = 0.5$（与 alpha 纹理中像素分类阈值一致），$b$ 在此处存在跳变。这是数据分布的自然结果——当前数据集中 $\alpha$ 在 0.23–0.42 之间无样本点。

## 7. 使用示例

```python
import numpy as np

def eff_neutral(B, alpha_init):
    """
    预测中性色 UI 在 HDR 亮度 B 下匹配 SDR 所需的 Effective Alpha。

    Parameters
    ----------
    B : float or array
        HDR 背景亮度 (nits), 有效范围 0-1000
    alpha_init : float
        UI 的初始平均不透明度, 有效范围 0.05-0.85

    Returns
    -------
    eff : float or array
        匹配所需的有效不透明度
    """
    B = np.asarray(B, dtype=float)
    a = alpha_init

    # Parameters
    b_fg, b_bg = 0.8176, 0.3427
    gamma, delta = 0.1597, 0.1000
    tau0, p_tau = 95.2, -0.6962

    # Asymptote: depends on which alpha_0 group the UI comes from
    # heuristic: α > 0.35 → FG group, else BG group
    if a > 0.35:
        b = b_fg
    else:
        b = b_bg
    # Guarantee b > α
    b = max(b, a)

    g0 = gamma * a ** delta
    tau = tau0 * (a / 0.5) ** p_tau

    return b - (b - g0) * np.exp(-B / tau)
```

## 8. 物理含义

**$g(0)$（$B=0$ 截距）：** HDR 窗口纯黑时，UI 看起来比 SDR 更透明（$g(0) < \alpha$）。视觉系统在黑电平下敏感度最高，半透明 UI 的通透感最强。

**指数上升：** 随着 HDR 背景亮度增加，背景对半透明 UI 的"亮度竞争"增强，需要提高 UI 的不透明度来维持与 SDR 相同的主观透明度。

**$\tau(\alpha)$（收敛速度）：** $\alpha$ 较高的 UI 收敛更快（$B_{90\%} \approx 170\ \text{nit}$），$\alpha$ 较低的 UI 收敛更慢（$B_{90\%} \approx 540\ \text{nit}$）。这是因为透明 UI 受背景亮度变化影响更大，需要更高的 HDR 亮度才达到稳定。

**$b(\alpha)$（高亮度渐近值）：** 在背景极亮时达到最终平衡态。$\alpha=0.71$ 的 UI 最终约需 $0.82$ 的有效不透明度；$\alpha=0.14$ 的 UI 仅需 $0.34$。两者都显著高于初始 $\alpha$，说明 HDR 高亮度对半透明 UI 的"冲淡"效应需要大幅补偿。
